# Future enhancements

This backlog describes functionality excluded from the first release without prescribing technical designs.

## Story block

The story block displays an ordered sequence of large content blocks whose animations follow the visitor's scroll position.

### Editorial and user value

It can animate metadata such as dates or information structure. Examples include an engineering career timeline, project evolution, or a ReactFunctors concept within the wider knowledge graph.

### Reason for deferral

The block is comparatively complex, while its content can initially be communicated with a text section or chapter. Deferral reduces first-release implementation effort.
