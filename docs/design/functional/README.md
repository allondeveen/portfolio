# Functional design

This section specifies the functional design of the portfolio website. It defines the requirements of the public website and content management system independently of their technical implementation, including expected application behaviour, content management, and interactions for visitors and editors.

Together with the [content strategy](../../content-strategy/README.md) and technical design, it forms the complete portfolio specification:

- The content strategy defines the purpose and organisation of the content.
- The functional design defines the required application behaviour.
- The technical design explains how those requirements are implemented.

## Scope

The public website scope includes:

- Website navigation
- Homepage functionality
- Project and article overviews and detail pages
- Contact page and forms
- Related projects and articles
- Search-engine optimisation
- Error handling and user feedback

The content management scope includes:

- Content creation and editing
- Draft and publication workflows
- Previews and revisions
- Reusable content blocks
- Media management
- Content relationships

Application architecture, technology choices, database design, deployment, and infrastructure are outside this section's scope.

## Intended audience

This section is primarily for engineers developing and maintaining the portfolio. Reviewers and collaborators can use it to understand the intended behaviour without knowing the implementation. Editors can use the content model, block library, content management, navigation, and forms documents to understand what content should include and why.
