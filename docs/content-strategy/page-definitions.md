# Page definitions

This document describes the purpose, audience, main content, secondary content, and calls to action for each page.

## Homepage

The homepage introduces the portfolio and directs visitors towards projects, articles, or the contact page.

**Audience**

- Recruiters
- Potential clients
- Software engineers

**Content**

- Hero
  - Background image or illustration
  - Name
  - Job title
  - Technologies
  - Call to action: contact
- Featured projects
  - Call to action: browse projects
- Featured articles
  - Call to action: browse articles
- Work experience
- Contact

## Projects overview

The projects overview provides an overview of engineering projects.

**Audience**

- Recruiters
- Potential clients
- Software engineers

**Content**

- Filters
- Project cards
- Contact

## Project page

The project page presents a project as an engineering case study.

**Audience**

- Recruiters
- Potential clients
- Software engineers

**Content**

- Project content
  - Hero
  - Sections
  - Gallery
- Related projects
  - Call to action: projects overview
- Contact

## Articles overview

The articles overview provides an overview of technical articles.

**Audience**

- Software engineers
- Recruiters

**Content**

- Filters
- Article cards
- Contact

## Article page

The article page presents a technical article as a case study of senior-level thinking.

**Audience**

- Software engineers
- Recruiters

**Content**

- Article content
- Related articles
  - Call to action: articles overview
- Contact

## Contact page

The contact page enables visitors to initiate contact.

**Audience**

- Recruiters
- Potential clients
- Software engineers

**Content**

- Hero
- Contact form
